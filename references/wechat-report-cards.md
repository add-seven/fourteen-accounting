# 微信消费报告卡片排版

## 触发场景

用户要求发送、调整或排查消费日报/周报/月报在微信里的展示效果，尤其是“排版不好看”“不直观”“换行错位”“色块/柱状图乱了”。

## 经验结论

微信聊天气泡里的纯文本不是等宽环境，长条字符、连续 emoji 色块、空格对齐都会随气泡宽度和字体发生换行错位。消费周报/月报需要直观展示分类占比时，优先生成 PNG 图片卡片，而不是纯文本伪图表。

## 推荐呈现

图片卡片建议包含：

- 标题：消费周报 / 消费月报
- 周期：明确日期范围或月份
- 汇总：总支出、笔数
- 焦点：最大单笔（周报）或峰值日（月报）
- 分类排行：分类名、金额、百分比、彩色横向进度条
- 底部提醒：核对微信 / 支付宝 / 订阅类自动扣款

视觉原则：

- 白色圆角卡片 + 浅灰背景，适合微信图片气泡。
- 每个分类占一行，文字和进度条固定布局，避免依赖文本空格对齐。
- 底部留足空间，生成后检查最后一项和页脚不重叠、不截断。
- 金额小数：整数不显示小数，非整数保留 1 位。
- 百分比四舍五入可能合计 99%/101%，可接受。

## 验证步骤

1. 实际运行报表卡片生成脚本，拿到 `MEDIA:/absolute/path.png`。
2. 用视觉检查确认：标题、周期、总支出、笔数、最大笔/峰值日、所有分类完整显示。
3. 重点看最底部分类和提醒区是否重叠、截断。
4. 更新 cron 后确认周报/月报任务使用图片脚本；月报非月末仍需静默退出。

## 反面样式

避免在微信里使用：

- `████░░░░` 这种长文本柱状条：容易挤断分类名和金额。
- `🟩🟩⬜⬜` 这种纯文本色块条：仍可能因 emoji 宽度和气泡宽度产生错位。
- 依靠空格或中文全角/半角混排对齐的表格。
